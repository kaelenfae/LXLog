LXLog Operation Manual

LXLog is a modern, high-performance, and privacy-respecting lighting paperwork application designed for lighting designers, production electricians, and programmers. It operates as a local-first Single Page Application (SPA), meaning all of your data, shows, and imported profiles remain directly in your web browser.

Privacy Statement
LXLog does not upload your show data or fixture profiles to any cloud database. All logs, schedules, and custom settings are stored locally in your browser's IndexedDB engine (using Dexie.js) and are never shared.

Core Architectural Features

  • Local-First Database: Utilizes browser-indexed storage. Your show is preserved between browser reloads without requiring active saves, though exporting backups is highly recommended.
  • GDTF Integration: Reads General Device Type Format (.gdtf) files to auto-populate attributes such as DMX footprint, power consumption, weights, and detailed DMX mapping.
  • Augment3d Support: Captures physical coordinates (X, Y, Z) and distance offsets to allow complete stage layout documentation.

Show & File Operations

LXLog allows you to manage multiple show files and reset workspace structures as needed using standard controls located in the application header and the Database Settings panel.

Creating a New Show

Click the New Show button in the header. The application will present a modal prompting you for the following metadata fields:

  • Show Name
  • Venue
  • Lighting Designer
  • Assistant Lighting Designer
  • Director / Producer / Company

Upon submission, a fresh show database is initialized in IndexedDB, clearing any current active fixture schedule.

Saving and Backing Up

Although IndexedDB retains data automatically, you can save a physical file of your show to disk by clicking Save LXLog in the header. This compiles the database tables (instruments, custom field configurations, targets) and downloads a unified .lxlog JSON file.

The download filename is automatically formatted as:
[ShowName]-[YYYY-MM-DD]-[HHMM].lxlog

Loading a Saved Show

To restore your workspace from a backup file:

  1. Click Open LXLog in the header.
  2. Select your saved .lxlog file.
  3. The application will restore your metadata, instruments, fixture profiles, custom fields, and custom Magic Sheet groupings.

Import Wizard

LXLog has a multi-step Import Wizard to integrate lighting data from other software environments. To access this wizard, click the Import button in the application header.

Import Modes
When importing external data, you must choose between two modes:
  • Replace Mode: Clears all existing database entries and initializes the schedule exclusively with the imported file. You will be prompted to enter new show metadata.
  • Merge Mode: Merges imported fixtures into your current show. Fixtures are merged and matched on channel and part designations. Existing data is preserved.

Supported Import Formats

Format Type File Extension Workflow Description
Lightwright Text .txt Processes tab-delimited files. Opens a column-mapping step to align Lightwright headers (e.g. Dimmer, Load, Accessory) with LXLog fields. Support for custom columns mapping is included.
ETC Eos CSV .csv Directly processes ETC Eos CSV patch exports. Auto-maps standard console headers and extracts coordinates and targets.
MA2 XML .xml Imports grandMA2 XML layer structures directly into the database.
MVR (My Virtual Rig) .mvr Note: Currently disabled in interface and marked as under development.

EOS CSV Target and Coordinate Extraction

The Eos CSV import logic is highly optimized for ETC console systems:

  • Coordinates Mapping: Location variables from the Augment3d engine are fully extracted:
    • Location_X is mapped to the instrument's X Coordinate and defaults to Distance from Center.
    • Location_Y is mapped to the Y Coordinate (depth).
    • Location_Z is mapped to the Z Coordinate (height).
  • Z Coordinate Fallback: If location coordinates are missing or equal to 0, they are left unpopulated in details, and Z defaults to the Default Grid Height (Z) configured in Settings.
  • Console Targets: The CSV parser extracts the TARGETS section from the Eos export file, parsing Groups, Presets, and Submasters, listing their ID number, Labels, and Channel strings to populate the EOS Targets Report.

Export Wizard

Clicking the Export button in the header opens a wizard allowing you to export your database back into standard files suitable for consoles or spreadsheet editors.

Supported Export Formats

  • ETC Eos CSV: Conforms strictly to ETC patch CSV requirements, allowing you to load your schedule straight into ETC console patch screens.
  • Lightwright (TSV): Generates a tab-separated text file conforming to Lightwright import specifications.
  • Generic CSV: Generates a standard comma-separated spreadsheet with all schedule columns, including custom user-defined fields.

Instrument Schedule Grid

The Instrument Schedule is the central workspace layout. It is built as a virtualized grid, allowing thousands of rows of lighting instruments to load and render with sub-millisecond responsiveness.

Grid Customization

  • Column Reordering & Visibility: Click the gear settings icon in the grid toolbar. You can drag and drop columns to reorder their layout, or check/uncheck columns to toggle visibility.
  • Column Resizing: Hover over the divider between headers. Click and drag to adjust the width of any column. Column widths are automatically persisted to local storage.

Data Entry Modes

  • In-Line Cell Editing: Double-click any cell in the table grid. The cell converts into an input field allowing direct modification.
  • Keyboard Editing: Select a cell and press Enter to activate the editor. Type the value and press Enter or Tab to save.

Keyboard Navigation & Grid Controls

The spreadsheet grid supports keyboard shortcuts for fast data entry:

Shortcut Key Action Performed
Arrow Keys Navigates the cell selection highlight up, down, left, or right across columns and rows.
Enter Activates the inline cell editor. While editing, pressing Enter saves changes and shifts focus to the cell directly below (Shift+Enter shifts focus up).
Tab Saves inline changes and moves focus to the cell to the right (Shift+Tab moves focus left).
Shift + Arrow Up / Down Selects a contiguous block range of instrument rows, starting from the current selection anchor.
Delete / Backspace Initiates deletion of all currently selected instruments. Shows a 4-second confirmation state in the footer to prevent accidental deletion.
Esc Exits active cell editing mode without saving, closes the Sidebar Details panel, or deselects all currently selected instruments. Focus is returned to the grid.

Selection & Bulk Editing

LXLog provides powerful batch processing options when editing multiple instruments at once.

Selecting Multiple Instruments

  • Checkbox Click-and-Drag: Hover over the row selection checkboxes on the left side of the grid. Click and drag down or up to select multiple rows.
  • Range Select: Click on a row, hold down Shift, and click another row to select all instruments between them.

The Bulk Edit Panel

When two or more instruments are selected, a floating Bulk Edit footer is displayed. Click **Bulk Edit** to open a collective detail view. Any fields modified in this panel will be updated across all selected instruments.

Sequential Auto-Numbering Patterns

When batch editing the Channel or Unit fields, you can use numbering patterns to sequentially number the fixtures:

  • Range Pattern (Start-End or Start-x): Typing 1-x, 1-10, or 101-x will auto-number the selected instruments sequentially starting from the left-hand integer (e.g. 101, 102, 103...).
  • Increment Pattern (Start++): Typing 1++ or 100++ will start numbering from the specified number and increment by 1 for each subsequent fixture in the selection list.
Batch Attribute Propagation
Updating GDTF-linked attributes (like DMX Footprint, Wattage, Weight, or Gel Frame Size) during a bulk edit automatically updates all fixtures in the show sharing those GDTF types.

Right-Click Context Menu

Right-clicking on any instrument row in the schedule displays a context menu for quick operations. If you right-click on an unselected row, it is automatically selected.

Available Context Menu Options

  • Edit (Enter): Opens the detailed instrument sidebar on the right side of the screen.
  • Duplicate: Duplicates the selected instrument(s). If multiple rows are selected, it duplicates the entire selection.
  • Select All "[Type]": Selects all instruments in the schedule that share the same fixture type (e.g., "Source Four 19deg").
  • Select All "[Position]": Selects all instruments in the schedule that share the same hanging position (e.g., "Electric 1").
  • Renumber "[Position]": Triggers a position renumbering prompt. It will automatically renumber unit numbers (from 1 to N) for all fixtures on that position based on the current active sort order.
  • Delete (Del): Deletes the selected instrument(s) (with confirmation).

Search & Grid Filtering

The schedule toolbar provides robust options to filter down your instrument grid. Click the **Filters** button to open the configuration panel.

Search Text

A real-time search input matches text across purpose, hanging position, type, channel, and note fields, filtering rows as you type.

Dropdown Filters

Narrow down the grid by selecting specific items from populated lists:

  • Type: Filter by fixture profile names.
  • Position: Filter by specific hang positions.
  • Color: Filter by specific gel colors.
  • Gobo: Filter by specific pattern templates.

Validation Filters

These tools allow electricians to check for data entry errors before exporting console patches:

  • Missing Address: Shows fixtures that do not have a DMX patch address.
  • Missing Channel: Shows fixtures that do not have a control channel.
  • Incomplete Only: Filters for fixtures missing core attributes (like fixture type or position).
  • Potential Duplicates: Highlights duplicate DMX addresses or channel numbers in red, helping you spot patch conflicts immediately.

Instrument Details Panel

When you click an instrument row or double-click to edit, the Master-Detail layout reveals the Details Panel on the right side of the viewport.

Coordinates Integration

If Show XYZ Coordinates is checked in settings, the details panel will display X, Y, and Z fields:

  • Distance / X: Displays the left/right offset from the center line.
  • Y Coordinate: Displays the front-to-back depth coordinate.
  • Z Coordinate: Displays the height coordinate. This field is automatically populated with the default grid height setting if the instrument is new.

Note-Taking and Timestamps

At the bottom of the details panel, the Notes section allows you to record multiple notes on individual instruments:

  • Notes show the username/system label and a localized timestamp.
  • Notes are useful for keeping track of repair requests, focus instructions, or circuit changes.
  • You can add notes of type "user" or "system".

Fixture Library Sync

When selecting an Instrument Type, the details panel checks your local GDTF library. If a match is found, it automatically retrieves and populates the fixture's DMX footprint, wattage, weight, and gel frame size, eliminating repetitive typing.

GDTF Fixture Library

The Fixture Library manages device definitions (.gdtf) to automate instrument scheduling.

Importing Fixture Profiles

Click Import GDTF to select a .gdtf file from your computer. The GDTF parser will extract physical, DMX, and graphical data, adding it to your show's fixture definition database.

Profile Tabs

Clicking on any fixture card in the library opens a modal showing four tabs:

  1. DMX Map: Displays unrolled DMX channel layouts, listing channels (e.g. Pan, Tilt, Color1, Cyan), bit resolutions, and default value ranges.
  2. Wheels: Displays slot visualizations for color and gobo wheels, including manufacturer descriptions and hex colors or slot images.
  3. Physical: Displays physical specifications (weight, wattage, dimensions, luminous flux, beam angle, and connectors).
  4. Raw XML: Displays the raw XML layout of the GDTF file, allowing advanced users to inspect the underlying structure directly.

Generic Profiles

If you enter a fixture type anywhere in the application—including the main schedule grid, the details editor, the bulk "Add Instruments" form, or via file imports (Lightwright, Eos, MA2)—LXLog automatically creates a Generic Profile in the Fixture Library. You can manually adjust its default attributes (such as wattage, weight, or DMX footprint) in the details panel, which will apply to all matching generic fixtures across the show.

DMX Universe View

The DMX Universe View provides a visual grid mapping the 512 DMX slots of a chosen universe. It is accessed via the side navigation bar.

Grid Visualization Key

  • Solid Highlight: Identifies the start address of a patched fixture.
  • Muted Highlight: Indicates subsequent slots occupied by the fixture's DMX footprint.
  • Red Highlight (Overlap): Highlights address overlap conflicts, showing where two or more fixtures are patched to the same DMX address.

Interactivity

  • Hovering over any occupied slot displays a tooltip listing the channel, part, instrument type, and address coordinates.
  • Clicking on any cell navigates the application directly to the details panel for that fixture, allowing quick patch corrections.

Print Center PDF Bundler

The Print Center is a tool for bundling multiple project reports into a single, cohesive PDF document.

Printing Steps

  1. Check the reports you wish to compile (e.g. Channel Hookup, Hanging Schedule, Patch).
  2. Select the page layout orientation (Portrait or Landscape).
  3. Toggle the Include Combined Cover Page checkbox.
  4. Click Generate Combined PDF. The application will render and download a single file.

Schedules & Reports List

LXLog offers several specialized reports in the sidebar. All reports support orientation toggling, page breaking, and individual PDF downloads.

Channel Hookup

A report sorted numerically by Channel and Part.

  • Part Notation: Secondary parts are formatted based on Settings (e.g. P2, .2, hidden, or shown as duplicates).
  • Color Swatches: Checkboxes toggle visual gel swatches next to gel colors.

Hanging Schedule

A report grouped by hanging Position, and sorted by Unit number. Shows a summary of unit counts and total wattage load at the bottom of each position.

Magic Sheet

An interactive masonry-layout report displaying groups of channels:

  • Drag and Drop: Drag the hamburger icons to visually arrange card groups.
  • Group Options Menu: Click the card menu to configure:
    • Lock Layout: Prevent dragging.
    • Hide Card: Hide the card from screen and prints.
    • Sort Order: Low-to-high or high-to-low channel numbers.
    • Fill Direction: Fill channels from bottom-up or top-down.
    • Columns: Grid columns layout (1 to 20 columns).
    • Card Width: Card column spans (1/3, 2/3, or full width).
  • Dominant Color Gradient: Cards automatically color their borders and backgrounds based on the dominant gel color in that group.
  • Partial Row Distribution: Partial rows are centered and distributed evenly for a clean appearance.

Patch Report

A compact patch listing sorted by Channel and Address. It supports multi-column layouts (Auto/1/2/3/4 columns) and a "Group by Type" toggle.

Equipment List

An alphabetical summary listing total quantities of each unique instrument type.

Cutting List

Counts gel cuts for the show. Group by Color (gel colors with size counts) or by Frame Size (frame sizes with color counts). Auto-splits gel chains (e.g. R02 + R80 counts as two separate gel cuts).

Power Report

Summarizes total fixture counts and total wattage loads for each hanging position.

EOS Targets

Displays Groups (emerald), Presets (purple), and Subs (amber) imported from an EOS CSV file.

Settings & Options

The Settings Modal is accessed via the gear icon in the main header and is divided into several sections:

Show Information

Allows editing of show metadata (Name, Venue, Designer, ALD, Director, Producer, Company) to populate cover pages and report headers.

Report Settings

  • Unit System: Select Feet (ft) or Meters (m) for coordinates.
  • Default Grid Height (Z): Prefills the height coordinate (Z) on new instruments and imports.
  • Spacing & Scaling: Adjusts print margins and layouts.

Interface Settings

  • Universe Separator: Select colon (:) or slash (/) formatting (e.g. "2:1" vs "2/1").
  • Always Show Universe 1: Toggles display of "1:1" vs just "1".
  • Show XYZ Coordinates: Toggles the visibility of coordinate input fields in the details panel.

Themes

Select from several UI themes, including Slate, Amber, Rose, Emerald, Sapphire, Velvet, Cyberpunk, and OLED Black.

Database Management

  • Reset Show: Deletes all instruments, targets, and show data (non-reversible).
  • Reset Magic Sheet: Restores Magic Sheet layouts and sorting configurations to default values.

Global Custom Fields

Allows you to define custom columns (e.g. "Circuit Name", "Proportion", "Purpose Details"). Once defined, these custom fields will display as grid columns in the schedule and input fields in the details panel.
